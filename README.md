# 2048

经典数字合并游戏 **2048** 的网页实现。单文件、零依赖，双击 `index.html` 就能玩。

## 玩法

用方向键移动所有方块，相同数字的方块相撞会合并成它们的和。每走一步，空位会随机出现一个 `2` 或 `4`。
凑出 **2048** 即获胜，之后还可以继续挑战更高分。

## 功能

- 4×4 棋盘，滑动与合并都有动画
- 键盘（方向键 / `WASD` / `HJKL`）、鼠标拖拽、手机滑动三种操作方式
- 得分与**最高分**记录（存在 `localStorage`，刷新不丢）
- **撤销**上一步（保留最近 60 步）
- 达成 2048 弹出胜利界面，可点「继续挑战」继续玩
- 无路可走时自动判定游戏结束
- 响应式布局，手机浏览器可用

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动方块 |
| `Z` | 撤销上一步 |
| `R` | 重新开始 |

## 本地运行

不需要任何构建步骤，直接用浏览器打开即可：

```bash
# 方式一：直接打开
start index.html        # Windows
open  index.html        # macOS

# 方式二：起一个本地静态服务（推荐，避免个别浏览器的 file:// 限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 运行测试

`test.js` 是一个无依赖的测试脚本：它用一个极简的 DOM 桩在 Node 里跑**真实的游戏脚本**，
再用合成的键盘事件驱动游戏，分三个阶段校验：

1. **随机走子** —— 每一步都检查不变量：数值必须是 2 的幂、格子不能重叠、
   有效走子必定只新增一个 `2` 或 `4`、计分与合并严格一致、终局判定正确
2. **撤销与贪心对局** —— 校验撤销能精确还原局面，并用一层探测式贪心 AI 打到 256
3. **胜利流程** —— 把胜利阈值临时改成 16，验证胜利弹层、「继续挑战」恢复对局、
   以及胜利界面期间输入被锁定

```bash
node test.js
```

预期输出：

```
phase 1: random play invariants
phase 2: undo + greedy play
phase 3: win flow (WIN_VALUE patched to 16)

ALL CHECKS PASSED
```

## 实现说明

几个值得一提的细节：

- **滑动动画**：每个方块是一个常驻的 DOM 元素，位置靠 `transform: translate()` 过渡实现，
  而不是每帧重建节点。外层 `.tile` 负责位移，内层 `.tile-inner` 负责 `scale()` 的弹出动画——
  两者分离，避免两套 `transform` 互相覆盖。
- **新块弹出**：使用 `animation-fill-mode: backwards`，让延迟期间停留在 `0%` 关键帧（`scale(0)`），
  于是「先滑动、后弹出」的节奏能自然地衔接上。
- **层级**：正在滑出的残影 `z-index: 1` < 普通方块 `2` < 刚合并出的方块 `3`，保证残影被压在下层。
- **合并**：移动的方块和被撞到的目标方块都会被标记为消亡并做淡出处理，同时在目标格生成合并后的新块。
